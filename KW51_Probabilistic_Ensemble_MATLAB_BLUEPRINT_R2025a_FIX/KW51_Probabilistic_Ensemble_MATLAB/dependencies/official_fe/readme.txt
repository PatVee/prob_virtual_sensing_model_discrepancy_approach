This is a readme-file for the finite element (FE) model of railway bridge 
KW51 in Leuven, Belgium.

- The model is developed by Kristof Maes, Menno van de Velde and Geert 
  Lombaert, affiliated to the Structural Mechanics Section of KU Leuven, 
  Belgium

- The model is developed in the open source finite element toolbox for 
  MATLAB, Stabil [1], developed at the Structural Mechanics Section of KU 
  Leuven. 

    [1] S. François, M. Schevenels, D., Dooms, M. Jansen, J. Wambacq, 
        G. Lombaert, G. Degrande, and G. De Roeck. Stabil: an educational 
        Matlab toolbox for static and dynamic structural analysis. 
        Computer Applications in Engineering Education, 29(5):1-18, 2021.
        https://doi.org/10.1002/cae.22391

- The Stabil toolbox can be downloaded at the following website:

    https://bwk.kuleuven.be/bwm/stabil
    
- The model was developed in Stabil version 3.1, [1].

- The model is accompanied by two application examples, one for a quasi-
  static simulation of a train passage and one for a modal analysis.

- An up to date list of comments including errata detected after release 
  of the finite element model can be found at bwk.kuleuven.be/bwm/kw51.

- The directory contains the following items:

    * 'blueprints/' (folder)

        Folder containing the blueprints of the structure underlying the 
        model, in PDF format. File 'list_of_blueprints.pdf' provides a list 
        of the blueprints with their label and description.

    * 'overview.pdf'

        Overview of the geometry of the bridge, labeling of the tracks
        (A/B), definition of the global reference coordinate system (GCS), 
        labeling of the bridge sides (South/North, Brussels/Leuven), 
        numbering of the diagonals (1 - 16) and bearings (N1 - N4).

    * 'model_kw51.m' 

        MATLAB function containing the finite element model of railway 
        bridge KW51.

    * 'simulate_trainpassage.m'

        MATLAB script for a quasi-static simulation of a train passage, in 
        accordance to the following reference:

        [2] K. Maes and G. Lombaert. Validation of virtual sensing for the 
            reconstruction of stresses in a railway bridge using field data  
            of the KW51 bridge. Mechanical Systems and Signal Processing, 
            190(110142):1-16, 2023. 
            https://doi.org/10.1016/j.ymssp.2023.110142

        This script makes use of the FE model in 'model_kw51.m', 
        'select_sensors.m' for the selection of the sensor locations 
        considered in the monitoring, [4,5], and 'xrail_2_P.m' for the 
        composition of the load vector.
    
    * 'select_sensors.m'
        
        MATLAB function that generates output selection matrices which, by 
        multiplication with the vector containing the response in all 
        degrees of freedom, provides the measured quantities of interest of 
        railway bridge KW51 [4,5].

        This function generates the MATLAB file 'sensor_definition.mat', 
        which contains the selection matrices and the corresponding sensor 
        labels in accordance to [4,5].

    * 'sensor_definition.mat'
	
        MATLAB file containing the selection matrices and the corresponding 
        sensor labels in accordance to [4,5]. This file is generated by 
        MATLAB function 'select_sensors.m'.

    * 'xrail_2_P.m'
        
        MATLAB function that generates the equivalent load vectors for 
        given axle loads at a given location and for given train speeds, 
        taking into account both gravitational and centripetal forces, in
        accordance to [2]. 

        This function includes multiple auxiliary functions and generates 
        the MATLAB file 'plate_areas.mat', which contains the areas 
        assigned to the nodes of the plate elements composing the ballast.

    * 'plate_areas.mat'

        MATLAB file containing the areas assigned to the nodes of the plate 
        elements composing the ballast layer. This file is generated by 
        MATLAB function 'xrail_2_P.m'.

    * 'force_distribution.pdf'

        Illustration of the force distribution over the nodes of the plate 
        elements composing the ballast layer.

    * 'modal_analysis.m'
        
        MATLAB script for a modal analysis using the finite element model 
        of railway bridge KW51, in accordance to the following reference:

        [3] K. Maes, L. Van Meerbeeck, E. Reynders, and G. Lombaert.  
            Validation of vibration-based structural health monitoring on 
            retrofitted railway bridge KW51. Mechanical Systems and Signal  
            Processing, 165(108380):1-24, 2022. 
            https://doi.org/10.1016/j.ymssp.2021.108380

        This script makes use of the finite element model in 'model_kw51.m' 
        and 'select_sensors.m' for the selection of the sensor locations 
        considered in the monitoring, [4,5].

    * 'toolbox/' (folder)

        Folder containing auxiliary MATLAB functions for plotting.
